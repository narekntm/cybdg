About – User Management Sandbox

Project Overview

This sandbox is designed to demonstrate frontend automation with dynamic UI interactions, server-side validation, and end-to-end CRUD operations. It serves as a training tool for Cypress and modern web testing techniques.

Features & Functionality

  • Add, edit, delete users dynamically.
  • Toggle user status (Active/Inactive).
  • Admin-only restrictions for deleting Admin users.
  • Persistent in-memory server with reset functionality.
  • Modularized CSS and JS structure for better maintainability.
  • Client and server-side validation with error reporting.
  • Toast notifications for form actions.
  • Pagination and search functionality.

Validation Rules

  • Name: 1–20 alphabetic characters, no spaces or symbols.
  • Role: Required (Admin, Viewer, Editor).
  • Age: Required, number between 1 and 99.
  • Email: Required, valid format, must be unique.
  • Gender: Selection required.

User Flow

  1. User opens the dashboard and views all existing users.
  2. They can search and paginate through the user list.
  3. To add a user, they click Add New User, fill the form, and submit.
  4. To edit, they click the edit icon, modify data, and save.
  5. To delete, they confirm deletion in the modal prompt.
  6. Admins can delete Admin users. Others are restricted.
  7. Status can be toggled without any modal confirmation.

Backend API Endpoints

  • POST /api/login – Admin login.
  • GET /api/users – Get all users.
  • POST /api/users – Add user (validates + checks uniqueness).
  • PUT /api/users/:id – Update user.
  • DELETE /api/users/:id – Delete user (admin check).
  • PATCH /api/users/:id/status – Toggle user status.
  • POST /api/reset – Reset server to default data.

Test Automation Use Cases

  • UI testing: Form submission, validation, modals, button states.
  • API testing: Verify each endpoint response and state change.
  • DOM interaction: Dynamic table content, pagination, search filtering.
  • Negative testing: Invalid credentials, duplicate emails, missing fields.
