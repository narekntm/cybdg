# 🧪 HA_04 – TypeScript & Cypress Practice: Inventory Manager

## 🧭 Objective

Practice TypeScript's type system inside Cypress tests by interacting with a custom-built HTML sandbox page: **Inventory Manager**.

This assignment focuses on:

- Modeling data using `interfaces` and `enums`
- Using `type` aliases
- Writing Cypress UI tests with type safety
- Validating dynamic UI behavior

---

## 📁 File Locations

| Resource          | Path                                                      |
| ----------------- | --------------------------------------------------------- |
| HTML Page         | `Resources/htmls/inventory_manager/index.html`            |
| Cypress Test File | `Cypress/Tests/UI/inventory_manager/inventory_manager.ts` |

---

## ⚙️ Getting Started

1. Start a local server to host the HTML file:

   ```bash
   npm run serve:UI
   ```

2. Access the page at:
   `http://127.0.0.1:8080/Resources/htmls/inventory_manager/index.html`

3. Create your Cypress test file under:
   `Cypress/Tests/UI/{Your Name}/inventory_manager/inventory_manager.ts`

---

## ✅ Tasks

### 1. Validate Dropdowns

- Ensure all values in `ProductCategory` and `ProductStatus` appear as `<option>` in the respective `<select>` fields.

---

### 2. Add and Verify Product

- Create a `Product` object in your test
- Fill the form with the product's data
- Submit the form
- Validate the product row appears in the table with matching values

---

### 🔁 Bonus Tasks

- Use `type ProductField = keyof Product` to dynamically test input field population
- Write a reusable helper method to fill the form from a `Product` object
- Test multiple product variations using `enum` combinations

---

## 📌 Submission Checklist

- [ ] Cypress test uses `enum`, `interface`, and `type` features
- [ ] Test validates dropdown content
- [ ] Product is added and verified via the DOM
